1. 回帰不連続デザインとは

回帰不連続デザイン（regression discontinuity design, RDD。不連続回帰デザインとも呼ぶ）は、準実験法の一つである。特定の推定手法の名前ではなく、データがどのように発生したかという仕組みに注目した分析の考え方である。

使えるのは、ある個人がトリートメントグループ（処置を受ける側）とコントロールグループ（受けない側）のどちらに入るかが、観測できる変数がある閾値（しきいち）を上回るかどうかで決まっている状況である。

ポイント閾値のすぐ上の人とすぐ下の人は、処置を受けたかどうか以外はほとんど同じはずである。だから両者の結果の差を、処置の効果とみなせる。これがRDDの基本的なアイデアである。

2. 例：補講授業の効果を調べる

ある大学で、前期の試験の点数が \(c\) 点未満の学生に補講を実施する。後期の試験を受ける学生には、前期に補講を受けた学生と受けていない学生がいる。補講の学習効果を知りたい。

学生 \(i\) について、記号を次のように決める。

記号意味データの変数
\(Z_i\)前期の試験の点数（割り当てを決める変数）Z
\(Y_i\)後期の試験の点数（結果）Y
\(D_i\)補講に参加していれば1、していなければ0D（あとで作る）
\(Y_{1i}\)補講に参加した場合の後期の点数どちらか一方しか観察できない
\(Y_{0i}\)補講に参加しなかった場合の後期の点数

補講への参加は、前期の点数 \(Z_i\) だけで次のように決まる。

\[ D_i = \begin{cases} 1 & \text{if } Z_i < c \\ 0 & \text{if } Z_i \geq c \end{cases} \]

実際に観察できるのは \(Y_{1i}\) と \(Y_{0i}\) のどちらか一方だけである（前期の点数に応じて決まる）。この例では \(c = 60\)、つまり前期の点数が60点未満の学生が補講を受けている。使うデータは、200人分の \((Y_i, Z_i)\) である。

4. 散布図を描く

横軸に前期の点数 Z、縦軸に後期の点数 Y をとって散布図を描く。plot(横軸, 縦軸) の順に指定する。

つまずきやすい点plot(exam_rdd) と書いても図は描けるが、データの列の順番どおりに軸が決まるため、横軸と縦軸が逆になってしまう。下で試して、上の図と比べてみよう。分析したい関係（何が何に影響するか）に合わせて、軸は自分で指定したほうがよい。

前期の点数が高い学生ほど、後期の点数も高いという右上がりの傾向がある。補講の境目である60点のところに縦線を引き、補講を受けた学生（60点未満）と受けていない学生で色を分けてみよう。

考えてみよう
  • 60点の少し上（たとえば60〜65点）と少し下（55〜60点）の学生を見比べると、後期の点数はどちらが高そうか。
答えの例を見る
図を見ると、前期が60点の少し下だった学生のほうが、後期の成績が平均的には高い傾向がある。全体としては右上がりなのに、60点のところで点の集まりが段差のように下にずれている。次の節で、実際に平均を計算して確かめる。

5. 60点の前後で平均を比べる

前期が60点以上65点未満の学生と、55点以上60点未満の学生について、後期の平均点を求める。exam_rdd$Y[条件] と書くと、条件にあてはまる学生の Y だけを取り出せる。条件を2つとも満たす、は & でつなぐ。

前者は約62.07点、後者は約72.73点になる。60点より少し下で補講を受けた学生のほうが、後期の成績が10点以上高い。

前期の試験で60点の少し上と少し下の学生の間には、学力の差はほとんどないはずである。それなのに後期の点数にこれだけの差があるのは、補講の効果だと考えてよいのではないか。

注意前期で60点を下回った学生が「まずい、単位を落としそうだ」と思って自分で勉強したことが効いている可能性もある。この場合、補講がなくても成績は上がったかもしれない。RDDで分かるのは「60点を下回ったこと」によって生じた差であり、それが補講そのものの効果だと言うには、ほかに60点を境に変わることがないかを考える必要がある。

やってみよう：比べる幅を変える

上では60点の前後5点ずつで比べた。この幅を2点、5点、10点と変えると、差はどう変わるだろうか。それぞれの幅に入る人数も表示する。

考えてみよう
  • 幅を狭くすると、どんな良いことがあり、どんな困ったことがあるか。
答えの例を見る
幅を狭くするほど、比べる2つのグループの学力は似てくるので、比較は公平になる（バイアスが小さい）。その一方で、幅に入る人数が少なくなり、平均がたまたまの値に左右されやすくなる（ばらつきが大きい）。逆に幅を広げると人数は増えるが、右上がりの傾向の影響を受けて、60点から離れた学生どうしを比べることになる。次の節以降の回帰分析は、この右上がりの傾向を直線で取り除いたうえで、60点の位置での差を求める方法である。

6. トリートメント効果の識別：連続性条件

補講を受けた場合と受けなかった場合で後期の点数に違いがあるとしたら、前期の点数 \(Z\) と後期の点数の期待値（平均）の関係は、次の図のようになっているはずである。

実際に観察できるのは、\(c\) 以上については補講を受けていないデータ、\(c\) 未満については補講を受けたデータだけである。そこで、次の仮定をおく。

連続性条件前期の試験の点数 \(Z\) が \(c\) に近い個人どうしは比較可能である。つまり、もし補講という制度がなければ、後期の点数の期待値は \(c\) のところでなめらかにつながっている（ジャンプしない）。

この条件が成り立つなら、\(c\) のところで条件付き期待値がどれだけジャンプしたかを見れば、補講の効果 \(\tau\) が分かる。式で書くと、\(c\) のすぐ下からの極限と、すぐ上からの極限の差である。

\[ \tau = \lim_{z \uparrow c} \mathbf{E}[Y_i \mid Z_i = z] \;-\; \lim_{z \downarrow c} \mathbf{E}[Y_i \mid Z_i = z] = \mathbf{E}[Y_{1i} - Y_{0i} \mid Z_i = c] \]

この \(\tau\) は、前期の点数がちょうど \(c\) の学生にとっての補講の平均的な効果（条件付平均トリートメント効果）である。

確かめてみよう：60点の前後で人数が不自然に偏っていないか

もし学生が「補講を受けたい（受けたくない）」と考えて自分の点数を調整できるなら、60点の直前や直後に人が集まり、閾値の前後の学生は比較可能でなくなる。前期の点数のヒストグラムを描いて、60点のところに不自然な山や谷がないかを見てみよう。

7. 回帰分析で効果を推定する（線形の場合）

前期の点数が後期の点数に与える影響が、補講あり・なしのどちらについても直線（線形）で表せるケースを考える。つまり、\(\mathbf{E}[Y_{1i} \mid Z_i]\) と \(\mathbf{E}[Y_{0i} \mid Z_i]\) がどちらも \(Z_i\) の一次関数であると仮定する。

ステップ1：補講ダミー D を作る

補講を受けていると1、受けていないと0になる変数 D を作る。mutate() は、データに新しい変数（列）を追加する関数である。ifelse(条件, 当てはまるときの値, 当てはまらないときの値) で0と1を作る。

tidyverse と dplyr教科書では library(tidyverse) と書いている。mutate() や %>% は tidyverse に含まれる dplyr パッケージの機能なので、ここでは読み込みの軽い library(dplyr) にした。RStudioでは library(tidyverse) のままでも同じ結果になる。パッケージを使わずに exam_rdd$D <- ifelse(exam_rdd$Z < 60, 1, 0) と書いてもよい。

ステップ2：推計式を決める

知りたいのは、前期の点数がちょうど60点のところでの補講の効果である。そこで推計式を次のようにする。

\[ Y_i = \alpha_0 + \tau \cdot D_i + \beta_0 \cdot (Z_i - c) + (\beta_1 - \beta_0) \cdot D_i (Z_i - c) + \varepsilon_i \]

\(Z_i - c\) を使うのは、60点の位置を横軸の0に合わせるためである。こうすると、補講を受けた人と受けていない人の境目である前期60点のところでの差が、\(D_i\) の係数 \(\tau\) として直接求まる。

\(D_i(Z_i - c)\) は交差項で、補講あり・なしで直線の傾きが違ってもよいようにするためのものである。\(D_i\) に0と1を入れてみると、各係数の意味が分かる。

グループ式（\(\varepsilon_i\) は省略）60点の位置（\(Z_i - c = 0\)）での値
補講なし（\(D_i = 0\)）\(\alpha_0 + \beta_0 (Z_i - c)\)\(\alpha_0\)
補講あり（\(D_i = 1\)）\((\alpha_0 + \tau) + \beta_1 (Z_i - c)\)\(\alpha_0 + \tau\)

60点の位置での2本の直線の高さの差が、ちょうど \(\tau\) になっている。

ステップ3：回帰分析をする

60点を0に合わせた変数 Zc（= Z − 60）を作り、lm() で回帰分析をする。D:Zc は D と Zc の交差項を表す。

\(\tau\) の推定値は D の行の Estimate である。補講を受けることが後期の試験の点数に与える効果は約13.0点であり、Pr(>|t|)（p値）がとても小さいので、統計的にも有意である。

出力の行対応する係数意味
(Intercept)\(\alpha_0\)補講なしの直線の、60点の位置での高さ
D\(\tau\)60点の位置での補講の効果
Zc\(\beta_0\)補講なしの直線の傾き（前期が1点高いと後期が何点高いか）
D:Zc\(\beta_1 - \beta_0\)補講ありとなしの傾きの違い

必要な数字だけを取り出すこともできる。coef() は係数、confint() は95%信頼区間を返す。

やってみよう：推定した直線を散布図に重ねる

推定した2本の直線を散布図に描き入れると、60点の位置での段差 \(\tau\) が目で見える。

確認問題
  • 補講を受けた学生の直線の傾き \(\beta_1\) はいくつか。coef(result) の値から計算してみよう。
  • 前期が55点だった学生（補講あり）の後期の点数の予測値はいくつか。
考え方を見る
\(\beta_1\) は Zc の係数と D:Zc の係数の和である。55点の学生は \(D = 1\)、\(Z_i - c = -5\) なので、予測値は \(\alpha_0 + \tau + \beta_1 \times (-5)\) になる。下のコードで確かめられる。

8. 推定結果を確かめる発展

上の推定は「データ全体で直線があてはまる」ことを前提にしている。この前提を変えても結果が大きく変わらないかを確かめておくと、結論に自信が持てる。

60点に近い学生だけで推定する

60点から遠い学生まで使うと、直線の仮定が正しくないときに結果がゆがむ。60点の前後10点（50点以上70点未満）の学生だけで同じ回帰をしてみよう。subset = で使う学生を絞れる。

数字の 10 を 5 や 20 に変えて、\(\tau\) の推定値と標準誤差（Std. Error）がどう変わるかを見てみよう。

条件付期待値が非線形の場合

前期と後期の点数の関係が直線ではなく曲線かもしれない。そのときは、\((Z_i - c)\) の2乗の項も入れて、曲線をあてはめる。I(Zc^2) は「Zcの2乗」を式の中で計算するための書き方である。

ポイント高い次数の項（3乗、4乗…）をむやみに増やすと、閾値付近の推定が不安定になりやすい。実際の研究では、閾値に近いデータだけを使って直線をあてはめる方法（局所線形回帰）がよく使われる。

ニセの閾値で試す（プラセボ・テスト）

本当は何も起きていないはずの点数（たとえば70点）を閾値とみなして同じ分析をすると、効果は0に近く、有意にならないはずである。補講を受けていない学生（60点以上）だけを使って試してみよう。

9. RDDが使えそうな状況を考える

RDDが使えるのは、ギリギリで基準を満たした人と満たさなかった人が、その後まったく異なる状況に置かれるケースである。

例
  • 高校入試で、有名校にギリギリで合格した人と不合格だった人のその後の所得を比べると、有名校で学ぶことの効果が分かる
  • BMIが一定の水準を超えると健康指導を受けることになる場合、その水準の前後で、その後の健康状態を比べる
  • タバコを吸い始めた年齢によって健康への影響が変わるなら、吸い始めた年齢が20歳より前か後かで、死亡率が違うのではないか
考えてみよう
  • ほかにどんなデータがRDDにふさわしいだろうか。「閾値（基準）」「閾値で変わる処置」「比べる結果」の3つを書き出してみよう。
  • その例で、閾値の前後の人が比較可能でなくなるのは、どんな場合だろうか。
考えるときのヒントを見る
  • 閾値の例：年齢（18歳、65歳）、所得や資産の基準、企業の従業員数、得票率50％、試験の合格点、誕生日（学年の区切り）など。
  • 比較可能でなくなる例：本人が数値を操作できる場合（基準をわずかに下回るように所得を調整する、合格点に届くよう採点が甘くなる、など）。また、同じ閾値で別の制度も同時に変わる場合は、どの制度の効果なのか区別できない。
  • 効果の範囲：RDDで分かるのは閾値付近の人にとっての効果である。閾値から遠い人（前期が30点の学生など）にも同じ効果があるとは限らない。

10. まとめ

  • RDDは、処置を受けるかどうかが観測できる変数の閾値で決まる状況を利用して、処置の効果を推定する準実験法である。
  • 鍵になる仮定は連続性条件：閾値の近くの人どうしは比較可能で、処置がなければ結果の期待値は閾値でジャンプしない。
  • 閾値での条件付き期待値のジャンプが、閾値付近の人にとっての平均的な効果 \(\tau\) になる。
  • 回帰分析では、割り当て変数を閾値が0になるように変換し（Zc = Z - 60）、処置ダミーとその交差項を入れる。処置ダミーの係数が \(\tau\) の推定値である。この例では約13.0点だった。
